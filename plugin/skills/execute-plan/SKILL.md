---
name: execute-plan
description: Execute and verify an approved Agent Engine plan through the durable local coordinator.
---

Read agent-engine-local.get_context before acting. The human imports the authenticated remote task using import_remote with repository, remote_task_id, project_id and verification tests as argv arrays. Standard/Deep imports require authoritative approval from the webapp. For managed operations issue exactly python3 <absolute-plugin-root>/scripts/bridge.py request --base64 <base64-json>, without shell composition. Envelope: {"operation":"...","arguments":{...}}. prepare(task_id) verifies backups before writes. apply(task_id,path,content,operation,destination,operation_id) writes only the active block scope; use a stable unique receipt ID. verify(task_id) records actual process results. retry(task_id,finding) consumes persisted budgets. review(task_id,findings) records semantic assertions after instrumented verification. next_block(task_id,tests) advances after the current block is verified. run_role(task_id,role,consent_id,delegation_id) runs one native Codex role through the coordinator; roles never delegate. Model policy is selected by the backend. Models configured with requiresVerification require a new explicit human consent for that exact delegation, consumed once within two minutes. Direct edits and interactive shells are not managed channels. release(task_id) requests completion only after every block and the final review. Report LOCAL_DONE_PENDING_SYNC until the server validates COMPLETED. Never create automatic commits.
