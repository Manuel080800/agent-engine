---
name: manage-memory
description: Search scoped memories and propose useful permanent knowledge after an Agent Engine task.
---

Retrieve only relevant owner/project memories. Distinguish source facts from model proposals. Never store credentials, source files, full diffs, stdout or complete conversations. Create memory-proposals with taskId, name, text, type, source and justification. Permanent promotion requires an explicit human approve/edit/reject action after task completion. Pending proposals do not block a correctly verified task. Equivalent or contradictory memory requires review. Explicit administrative memory CRUD is separate from automatic capture.
